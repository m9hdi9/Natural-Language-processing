# Lab 9 – Named Entity Recognition (NER)

This lab focuses on using **spaCy** for Named Entity Recognition (NER) in Python.

### Tasks Completed

- **Task 2:** Detect and visualize entities, and count PERSON and ORG entities.
- **Task 3:** Train a custom NER model for 20 iterations, save it, and test its predictions.

**Tools:** Python, spaCy, Jupyter Notebook.
