# Lab 10 – Introduction to Machine Translation

This lab focuses on Machine Translation using Python and LSTM neural networks.

### Tasks Completed
- **Task 1:** Explain the functions of Embedding, Encoder LSTM, Decoder LSTM, and Softmax layers.
- **Task 2:** Implement an English-to-French translation model using an LSTM-based Encoder-Decoder architecture.

### Tools
Python, TensorFlow, Keras, Pandas, NumPy, and Jupyter Notebook.

**Dataset:** English-French Translation Dataset (Kaggle).
