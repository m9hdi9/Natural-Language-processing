# Lab 11 – Attention with RNN

This lab focuses on understanding and visualizing the Attention Mechanism in Recurrent Neural Networks (RNN) using Python and PyTorch.

### Tasks Completed
- **Task 1:** Visualize attention weights for three questions and identify the words with the highest attention.
- **Task 2:** Compare attention weights between two similar questions and analyze how the model focuses on different words.

### Tools
Python, PyTorch, Pandas, Matplotlib, and Jupyter Notebook.

**Dataset:** Lab_11_QnA_Dataset.csv

**Status:** Both tasks implemented.
